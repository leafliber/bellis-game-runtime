# G2 任务卡：独立运行与 HSR 验证

**目标**是在 Windows 11 上以独立 Runtime 验证《崩坏：星穹铁道》（HSR）的有限任务。维护者已结束《魔法少女的魔女审判》的适配与复测。其运行结果保留原状态。

## 步骤

1. 固定[操作员许可源](../modules/game-bridge.md#独立运行)、实时核、适配版本和所选窗口。为 HSR 使用新的适配、任务、会话和测试批次身份。核对当前桌面与既有输入的释放状态。
2. 用合成游戏回归[输入权威](../architecture.md#权威)、[逐步验效](../modules/step-control.md)和未决隔离。将命令接纳、原生执行、新帧效果和最终释放分别记录。
3. 在已确认的[使用范围](../compliance.md#其它游戏)内记录 HSR 的版本、窗口、坐标变换、语言和可用场景。核对采集、有限输入、接管与释放，再用本游戏的新帧标定菜单、交互、探索或战斗所需的识别与技能。
4. 选择有可观察完成条件的短目标。由游戏侧规划、执行并核验每步效果。遇到未知界面、过时依据或结果未知时，记录原尝试并停止相关输入。记录人工干预、游戏内置辅助、模型用量与时延。
5. 在已验证的目标上增加连续片段，固定适配版本后再用留出内容验证。完成独立闭环后按 [G3](G3.md) 接入直播协作。

## 出口

- 独立运行只使用当前适配、操作员控制台、主进程和实时核。白名单、窗口、前台、时效和控制权都经实际核对。没有可加载适配包时停止启动。
- 本地完成 Windows 与 Linux 容器的完整检查。在新批次逐层提交 HSR 的环境、输入、单技能及短目标证据；每个结论都能对应原始观察、执行、效果、释放与已知人工干预。
- 控制权失效即停。效果未知保持隔离；已接纳、已执行、已释放分别按其原义报告。HSR 真实能力逐项以新运行记录验收。

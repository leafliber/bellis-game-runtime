# G2 任务卡：受监督的自动游玩（独立运行）

**目标**：不接 Bellis，操作员在场，Game Runtime 在《魔女审判》上自主推进一段完整剧情：对白推进，选项与审判经决策点由操作员给出结果，遇到坏结局时停下、得到继续后重来。输入只由实时核在操作员给出的许可下发出，任何失效都释放全部输入。合成游戏上快路径关闭时，通用视觉智能体的基准有结果。

**通用优先**：沿用 [G1](G1.md) 的原则。逐步控制器、通用视觉智能体、planner 与风险规则按[通用画面类型](../modules/perception.md#画面状态)写一次；《魔女审判》只写适配包里的画面映射、签名与快路径。快路径是对速度与可靠性的补充，关掉后智能体仍能推进，以合成游戏上的[离线回放基准](../modules/offline-tools.md#离线回放基准)衡量。

**平台**：同 [G0](G0.md)。本地模型推理在 CPU 上运行；云端模型只用 C-2 允许清单内的型号。

**前置**：C-2 的账号核对做完（协作奖励计划与套餐条款两项），第一次调用云端模型之前。

**必读**：模块文档[逐步控制](../modules/step-control.md)、[剧情记录与规划](../modules/narrative-planner.md)（规划、调用时机、游戏笔记、坏结局与重来）、[模型接入](../modules/models.md)、[实时核](../modules/realtime-core.md)的输入代理与启动与生命线、[核协议](../modules/core-protocol.md)的输入许可与动作块、[游戏桥](../modules/game-bridge.md)的独立运行、[感知](../modules/perception.md)的画面状态、[游戏适配包](../modules/game-adapter.md)的阅读节奏、快路径与风险、[离线工具](../modules/offline-tools.md)的标定与离线回放基准、[《魔女审判》适配](../games/witch-trial.md)；[技术基线](tech-baseline.md)中的 GR-09、GR-11、GR-13、GR-15、GR-17、GR-18、GR-19、GR-21、GR-23、GR-25、GR-27、GR-32、GR-33、GR-35、GR-36；[合规](../compliance.md)的 C-1 至 C-5；[真机探针](spikes.md)中的 GS-02、GS-05（余项）、GS-07。

## 范围

做：
- **操作员与输入**：操作员控制台与测试许可（GR-36）；真实输入后端（SendInput），持键账目的核验，低层钩子与接管检测，急停热键，静态禁区（GR-09）；实时核崩溃后自动重启（GR-35）。
- **感知与模型**：画面状态服务与通用画面类型（GR-32）；模型接入的薄客户端，按用途配置，允许清单与遥测（GR-11、GR-18）。
- **控制与规划**：策略后端契约与逐步控制器（GR-33、GR-13），含决策点、动作风险的四道防线（GR-21）与多步执行（GR-23）；通用视觉智能体（GR-13、GR-19）；planner 的摘要、笔记、关键帧（含播片）与决策候选（GR-17、GR-25）；坏结局与重来（GR-15）。
- **《魔女审判》与基准**：《魔女审判》的签名标定与快路径（对白推进、选项、审判、失败与重来）；离线回放基准与通用度指标（GR-27）。
- **探针**：GS-02、GS-07，以及 GS-05 的余项。

不做：
- 与 Bellis 的连接与看点标记（G3）。
- 提权时的计划任务启动：《魔女审判》不需要提权（GS-05）。
- 连续模式与动作块的定时调度（原神阶段，GS-08）。
- 技能库（GR-34）：在《魔女审判》出现重复的导航序列时再提前。
- 界面元素检测（GR-24，见 [G3 的 GS-09](spikes.md#gs-09-的评估)）。
- GPU 执行器。

## 步骤

1. **操作员控制台与测试许可。** 按 GR-36 实现控制台：
   - 它是实时核的许可源，以及主进程取目标、交出决策点的对端。
   - 一次测试会话就是测试许可：开始前确认前置条件，有时长上限，并记入会话记录。
   - 在核协议里写明操作员许可连接的消息。
   - 门禁：真实输入后端只能与一个许可源连接一起选出，同 G0 测试许可源的门禁。
   - 先接假输入后端与合成游戏测通。
2. **真实输入。** 按[注入](../modules/realtime-core.md#注入)实现 SendInput 后端：
   - 注入前后核对前台，强制执行白名单与静态禁区。
   - 释放后以 `GetAsyncKeyState` 核验，并定下新实例能否据此补发抬起。
   - 低层钩子识别真人接管与第三方注入，响应急停热键；实时核崩溃后自动重启（GR-35）。
   - GS-02 实测：先用合成游戏的窗口，再用《魔女审判》（只有左键点击）；释放时延在真实输入下实测。
3. **画面状态服务。** 按 GR-32 把 `scene@1` 扩展为画面状态服务：
   - 聚合签名、OCR 与智能体观察，给出带来源与置信度的画面状态。
   - “观察只能收紧、不能放宽”只在这里实现。
   - 实现通用画面类型的分类，合成游戏覆盖全部类型。
4. **模型接入。** 按[模型接入](../modules/models.md)：
   - 实现 `vlm@1` 的 OpenAI 兼容薄客户端，模型按用途配置，强制执行允许清单，记录遥测。
   - 图像按用途的规格裁剪缩小。
   - GS-07 对照各用途的型号与坐标约定；可用已存样本（C-3）。
5. **逐步控制器与动作风险。** 按[逐步控制](../modules/step-control.md)实现 `policy@1` 与逐步控制器：
   - 每一步的稳定判断，播片中不动作。
   - 定位吸附到 OCR 识别框；动作分类与重发规则；多步执行。
   - 决策点：独立运行中由控制台给出结果；有计时的到余量线执行排第一的候选。
   - 动作风险的四道防线。
   - 先在合成游戏上经假输入后端跑通。
6. **《魔女审判》的标定与快路径。** 按 C-5 在本机截图与录制上标定：
   - 标定项：选项、审判与坏结局的签名，审判发言区的 ROI，以及发言中可指出的词组的定位（[决策点](../modules/step-control.md#决策点)的字符级定位）。
   - 快路径：对白推进按[阅读节奏](../modules/game-adapter.md#阅读节奏)的通用缺省，以配音忙闲为辅，有最长等待兜底；选项开决策点。
   - 审判快路径：在发言轮播中收集发言与可指出的词组，作为候选开决策点；得到结果后，等那句发言在轮播中再出现时点击词组并选反驳。
   - 失败与重来按 GR-15。
   - GS-05 的余项随游玩补齐：坏结局与重来、审判超时、存读档、真实播片等。
7. **通用视觉智能体与 planner。** 按 GR-13、GR-19、GR-23 实现智能体，每次输出观察与动作，一次至多 3 步。按[规划](../modules/narrative-planner.md#规划)、[调用时机](../modules/narrative-planner.md#调用时机)与[游戏笔记](../modules/narrative-planner.md#游戏笔记)实现 planner：
   - 滚动摘要与笔记批量更新，审判发言、决策点与坏结局立即调用。
   - 播片结束时以关键帧加字幕调用一次。
   - 给决策点的候选标明已试过的选项。
   - 剧情记录的说话人按本次运行已见的名字归并，不按游戏：G1 验收中名字误读造成了缺口与角色分裂。
8. **离线回放基准。** 按 GR-27：
   - M0 回放可按配置替换策略后端，输入走假后端。
   - 统计命中、错点、拒绝、步数、调用次数与费用。
   - 合成游戏上关掉快路径跑通用视觉智能体的基准。
   - 记下《魔女审判》通用度指标的第二个数据点。
9. **验收。** 维护者在场，在控制台下独立运行《魔女审判》一段剧情，含对白、选项与一段审判讨论，同时录制；按出口逐项核对，M0 回放比对。结论改变设计时直接修改技术基线与相关文档。

## 出口

以下在 Windows 11 真机上实际运行通过，且 Linux 容器内的完整检查通过：

- **完整剧情**：操作员在场，独立运行下在《魔女审判》上自主推进一段完整剧情。
  - 对白推进不漏读。
  - 选项经决策点由操作员给出结果后执行。
  - 审判讨论中指出发言里的词组并选择反驳：决策点在计时内由操作员给出，到余量线仍没有结果时执行排第一的候选。
  - 遇到坏结局时上报并停下，得到继续后用游戏自带的重来入口重来，失败的选项在候选中标为已试过。这次游玩没遇到坏结局时，在合成游戏上验证，《魔女审判》上记为 PENDING。
- **风险与拒绝**：点击落在选择区域内被拒绝，改开决策点。四道防线生效：设置与存读档画面只允许返回，禁用词命中即拒绝，静态禁区由实时核拒绝，前置条件未确认不进入自动游玩。被拒的动作与原因可查。
- **释放与重启**：急停热键、许可过期（控制台暂停或退出）与真人接管后全部输入释放，释放时延在真实输入下实测，`GetAsyncKeyState` 核验没有残留按住的键；实时核崩溃后按 GR-35 重启，先释放再接受动作。
- **测试许可**：没有控制台会话或会话到时，实时核不发任何输入；真实输入后端不能与其它许可源一起选出。
- **模型**：云端模型只调用 C-2 允许清单内的型号，清单外的请求被拒绝；单步与多步的调用次数、成功率与错点率按 GS-07 对照记录。
- **基准**：`policy@1` 按策略后端契约实现，离线回放基准能替换后端；合成游戏上快路径关闭时通用视觉智能体的基准有结果；《魔女审判》的通用度指标记下第二个数据点。
- **写回**：GS-02、GS-07 的结论写回技术基线中的对应路线；GS-05 的余项写回[《魔女审判》适配](../games/witch-trial.md)。

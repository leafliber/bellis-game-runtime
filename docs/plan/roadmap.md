# 路线图

阶段划分见技术基线 GD-05。规则同 [Bellis 路线图](https://github.com/leafliber/bellis/blob/main/docs/plan/roadmap.md)：每个阶段有明确的出口；三平台 CI 只证明代码在各平台上能通过检查，阶段验收只在 Windows 11 真机上实测才算数，模拟与假后端通过不等于真机通过。每个阶段开工时写任务卡，范围超出任务卡时先找维护者确认。

```text
Bellis：        P2 真实互动 ─────────────► P3 游戏桥与魔女审判 ─► T1 公开试播
                                                 ▲
Game Runtime：  G0 骨架与实时核闭环 ─► G1 只读感知 ─► G2 受监督的自动游玩 ─► G3 游戏桥联调（与 P3 同步）
                                                                                   │
                                                                                   ▼
                                                               原神：探索与剧情 ─► 解谜 ─► 战斗
并行：VLA 研究（离线，Bellis D-05）
```

G0–G2 不依赖 Bellis，以[独立运行](../modules/game-bridge.md#独立运行)开发与验收；G3 依赖 Bellis P3 冻结游戏桥契约。

## G0 工程骨架与实时核闭环

- **内容**：仓库布局与统一检查入口、三平台 CI；核协议的生成管线；本机通道；主进程插件内核的最小实现；实时核作为子进程的启动、心跳与停止；帧环与 WGC 采集；动作块经假输入后端执行，[失效与释放](../architecture.md#失效与释放)中的情形在假后端上可证。
- **路线**：GD-01、GD-02、GR-01、GR-02、GR-03、GR-07、GR-28、GR-29。
- **探针**：GS-01、GS-03。
- **出口**：见 [G0 任务卡](G0.md)。

## G1 只读感知

- **内容**：音频环与配音检测；OCR；画面变化检测与《魔女审判》的画面签名；剧情记录；《魔女审判》游戏适配包的必需部分与语言核对；本机录制工具与离线回放基准的样本格式。不发出任何输入，维护者手动游玩时只读运行。
- **路线**：GR-04、GR-08、GR-10、GR-12、GR-14（剧情记录部分）、GR-16、GR-27；C-1。
- **探针**：GS-04、GS-05、GS-06。
- **出口**：维护者手动游玩一段剧情时，剧情记录逐句正确，完整、部分与缺口的判定正确；对白、选项与审判画面被正确识别；配音忙闲判定正确；同一段录制在 M0 回放中得到同样的结果。准确率与时延按 GS-04、GS-06 的口径实测记录。

## G2 受监督的自动游玩（独立运行）

- **内容**：真实输入后端、持键账目、低层钩子与接管检测、静态禁区；独立运行的操作员入口与测试许可；逐步控制器与《魔女审判》的快路径（对白推进、选项、计时审判、失败与重来）；通用视觉智能体；planner；风险等级的四道防线。决策点在独立运行中由操作员给出结果。
- **路线**：GR-09、GR-11、GR-13、GR-15、GR-17–GR-19、GR-21、GR-23、GR-25；C-2（账号核对须先完成）。开工前须登记并批准独立运行的操作员入口与测试许可的形式。
- **探针**：GS-02、GS-07；C-3 确认后，GS-07 才用已存样本对照云端模型。
- **出口**：操作员在场，独立运行下自主推进一段完整剧情：对白推进、无计时与有计时的选项（计时选项到余量线执行排第一的候选）、坏结局后的重来都正确执行；急停、许可过期与真人接管后全部输入释放，时延实测；被拒的动作与原因可查。

## G3 游戏桥联调（与 Bellis P3 同步）

- **内容**：与 Bellis 冻结游戏桥契约（[P3 契约提案](bellis-p3-proposals.md)）；锁定 Bellis 生成物（GD-03）；语义连接与控制连接；看点标记与暂缓推进；开播预检中的游戏前置条件；与 Bellis 宿主真机互通（GR-28）。
- **路线**：GD-03、GR-05、GR-06（游戏提权时）、GR-20；Bellis 侧见提案 P-01–P-08。
- **出口**：同 Bellis P3：私有测试直播间中完整推进一段剧情；无计时选项的投票或自选、有计时选项的自选都正确执行；急停后全部输入释放的时延实测。之后随 Bellis T1 公开试播。

## 原神阶段

按 Bellis 路线图“探索与剧情 → 解谜与小游戏 → 战斗”分步上线，每一步开播前按[合规](../compliance.md#其它游戏)复核。新增连续模式、模式仲裁（GR-26）、实时核的定时调度（GS-08）与 VLA 后端，以及界面元素检测（GR-24、GS-09）。经验快路径（GR-22）与游戏笔记（GR-25）在这一阶段面向第二款游戏推广。各步的任务卡在开工时写。

## VLA 研究（并行）

在本仓库离线推进，不进入直播（Bellis D-05）：同步采集工具（画面、键鼠与口述）、快策略原型、首动作时间与输入释放测试、原神离线评估。训练数据的限制见[合规](../compliance.md)。

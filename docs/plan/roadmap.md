# 路线图

阶段划分见技术基线 GD-05。规则同 [Bellis 路线图](https://github.com/leafliber/bellis/blob/main/docs/plan/roadmap.md)：每个阶段有明确的出口；本机的完整检查（Windows 真机与 Linux 容器，GR-29）只证明代码能通过检查，阶段验收只在 Windows 11 真机上实测才算数，模拟与假后端通过不等于真机通过。每个阶段开工时写任务卡，范围超出任务卡时先找维护者确认。

```text
Bellis：        P2 真实互动 ─────────────► P3 游戏桥与 HSR ─► T1 公开试播
                                                 ▲
Game Runtime：  G0 骨架与实时核闭环 ─► G1 只读感知 ─► G2 受监督的自动游玩 ─► G3 游戏桥联调（与 P3 同步）
                                                                                   │
                                                                                   ▼
                                                               原神：探索与剧情 ─► 解谜 ─► 战斗
并行：VLA 研究（离线，Bellis D-05）
```

G0–G2 不依赖 Bellis，以[独立运行](../modules/game-bridge.md#独立运行)开发与验收；G3 依赖 Bellis P3 冻结游戏桥契约。

## G0 工程骨架与实时核闭环

- **内容**：仓库布局与统一检查入口（含 Linux 容器内的检查）；核协议的生成管线；本机通道；主进程插件内核的最小实现；实时核作为子进程的启动、心跳与停止；帧环与 WGC 采集；合成游戏夹具（GR-30）：假采集源从它出帧，假输入后端的动作回送它；动作块经假输入后端执行，[失效与释放](../architecture.md#失效与释放)中的情形在假后端上可证。
- **路线**：GD-01、GD-02、GR-01、GR-02、GR-03、GR-07、GR-28、GR-29、GR-30。
- **探针**：GS-01、GS-03。
- **出口**：见 [G0 任务卡](G0.md)。

## G1 只读感知

- **内容**：音频采集、配音检测、OCR、画面变化与签名、剧情记录、适配声明及语言核对、本机录制与离线回放。当期旧游戏的只读证据见[退役索引](../games/witch-trial.md)。
- **路线**：GR-04、GR-08、GR-10、GR-12、GR-14（剧情记录部分）、GR-16、GR-27、GR-31；C-1、C-4、C-5。
- **探针**：GS-04、GS-05、GS-06。
- **出口**：见 [G1 任务卡](G1.md)。

## G2 受监督的自动游玩（独立运行）

- **内容**为操作员授权的独立游戏闭环、单一输入执行链、新帧验效与有界任务。HSR 使用本游戏的窗口、识别和技能重新建立基线。
- **路线**沿用 GR-09、GR-13、GR-15、GR-21、GR-23、GR-32、GR-33、GR-35 与 GR-36。
- **出口**见 [G2 任务卡](G2.md)。

## G3 游戏桥联调（与 Bellis P3 同步）

- **内容**：与 Bellis 冻结通用游戏桥契约（[P3 契约提案](bellis-p3-proposals.md)）；锁定 Bellis 生成物（GD-03）；语义连接与控制连接；看点标记与暂缓推进；开播预检中的游戏前置条件；与 Bellis 宿主真机互通（GR-28），在已独立验证的 HSR 片段上回接直播。
- **路线**：GD-03、GR-05、GR-20、GR-38，含 [GS-09](spikes.md#gs-09-的评估)。Bellis 侧见 [P3 契约提案](bellis-p3-proposals.md)。
- **出口**见 [G3 任务卡](G3.md)。私有测试直播按 Bellis P3 单独验收。

## 原神阶段

按 Bellis 路线图“探索与剧情 → 解谜与小游戏 → 战斗”分步上线，每一步开播前按[合规](../compliance.md#其它游戏)复核。新增连续模式、模式仲裁（GR-26）与连续模式的守卫条件、实时核的定时调度（GS-08）与接策略后端契约（GR-33）的 VLA 后端，通用技能库（GR-34），以及此前未做时实时核的计划任务启动（GR-06）。经验快路径（GR-22）与游戏笔记（GR-25）在这一阶段面向第二款游戏推广，条款允许的游戏上真人示范也作为候选来源。各步的任务卡在开工时写。

## VLA 研究（并行）

在本仓库离线推进，不进入直播（Bellis D-05）：同步采集工具（画面、键鼠与口述）、快策略原型、首动作时间与输入释放测试、原神离线评估。训练数据的限制见[合规](../compliance.md)。

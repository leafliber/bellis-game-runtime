# 真机探针

探针用来验证会影响设计的外部假设，结果不能替代阶段验收。规则同 [Bellis 真机探针](https://github.com/leafliber/bellis/blob/main/docs/plan/spikes.md)：在目标 Windows 真机上运行，记录日期、系统与驱动版本、游戏版本、命令、样本数、原始结果与限制；结果写入不入库的报告；结论改变设计时，直接修改对应文档与[技术基线](tech-baseline.md)。

游戏截图与录制按[合规](../compliance.md#合规确认)的 C-1 使用；已存样本发给云端模型须先确认 C-3；实测时编码助手截取含游戏画面的屏幕按 C-5。

第一版以跑通流程为先：兼容其它设备与环境的测试不在维护者的机器上跑，标为不测（维护者 2026-10-31 决定）。

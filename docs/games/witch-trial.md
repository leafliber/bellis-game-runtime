# 《魔法少女的魔女审判》适配

首个里程碑的游戏（Bellis D-06）。本文只写这款游戏特有的适配；通用机制见各模块文档，合规约束见[合规](../compliance.md#魔法少女的魔女审判)。适配包代码放在 `games/` 下，目录名在首个实现时定。

## 版本与语言

（GR-16）简体中文版，整局固定不换。

- 2026-10-28 读取 Steam 商店页：目前只有简体中文（界面与字幕）与日文（界面、全程配音与字幕），配音只有日文。
- 适配包写明语言 `zh-Hans`；签名中的 OCR 固定文字与锚点模板、各 ROI 与阅读节奏都按中文版标定。OCR 识别语言为简体中文，GS-04 按中文版采集样本，暂不准备日文配置。
- 启动时的语言核对按[游戏适配包](../modules/game-adapter.md#内容)的必需项执行；不支持中途换语言。
- 依赖原文文字游戏而译文没有处理好的推理，按[坏结局与重来](../modules/narrative-planner.md#坏结局与重来)或由操作员接管处理，不为此改用日文版。

## 运行要求

- 窗口化或无边框全屏；是否需要提权、失焦时的行为由 GS-05 普查。
- 只有逐步模式，模式仲裁始终选逐步控制器。

## 快路径

以下快路径是本游戏的必需项：对白推进与计时审判按[控制的组织](../architecture.md#控制的组织)中有时限的画面与高频动作须有快路径的规则；选项与失败与重来是本游戏的决定，让决策点与坏结局的识别不依赖模型（GR-15）。

| 快路径 | 内容 |
| --- | --- |
| 对白推进 | 名字栏与对白框的 OCR；文字完整、配音为闲且已过最短阅读时间后推进（[配音检测](../modules/perception.md#配音检测)） |
| 选项 | 识别选择画面，生成决策点 |
| 计时审判 | 识别审判发言与剩余时间；发言出现即增量计算候选，到余量线执行排第一的候选 |
| 失败与重来 | 以画面签名识别坏结局或游戏结束画面 |

这些快路径手写；[经验快路径](../modules/game-adapter.md#经验快路径)的记录可以先开启。

审判中点选发言里的某个词按[决策点](../modules/step-control.md#决策点)中字符级定位的规则处理，可行性由 GS-04、GS-05 实测。计时的时长与超时结果由 GS-05 普查。

## 动作白名单与风险

- 不允许长按。
- 快进、自动模式、回想与存读档不进动作白名单。
- 预计为买断制、无内购（GS-05 核对）；存读档与设置画面只允许返回。
- 坏结局画面上游戏自带的重来入口，只在画面类型为坏结局时加入白名单。游戏没有重来入口、只能回标题读档时，同样按状态加一条受限的“读最近的自动存档”流程，形式由 GS-05 普查后定。
- 不在决策点前主动存档；跨场直播的存档靠游戏的自动存档，或由操作员在下播时处理。

# 模型接入

主进程调用语言与视觉模型的唯一方式：一个 OpenAI 兼容的薄客户端，按用途配置模型，在外发前强制执行合规允许清单。普通插件 `vlm@1` 与 `planner@1` 共用这个客户端（GR-11、GR-18）。谁在什么时候调用模型见[总体架构](../architecture.md#模型调用)。G2 实现。

## 职责

- 按用途选择端点、型号与参数，发出请求，校验结构化输出。
- 外发前核对允许清单，裁剪缩小图像，换算返回的坐标。
- 按用途记录调用的型号、用量、时延与失败。

## 不负责

- **决定何时调用。** 由各调用方决定（[逐步控制](step-control.md)、[剧情记录与规划](narrative-planner.md#调用时机)）。
- **采信结果。** 模型输出只是候选；坐标须经[定位与吸附](step-control.md#定位与吸附)核验才可执行。

## 客户端

- 按 OpenAI 兼容的 Chat Completions 自写薄客户端，不引入厂商 SDK（同 Bellis R-17）。
- 云端优先；本地小型 VLM（候选为 Qwen-VL 系列的量化版）作智能体用途的降级。
- 不在实时路径上；每次调用有超时，结果只作候选。
- 游戏文本与画面在提示词中以引用的数据出现，不当作指令；输出按结构化格式校验。
- `vlm@1` 的权限为 `net.egress:<主机>` 与 `secret:<名字>`，只持有所用厂商的凭据。Game Runtime 使用单独的方舟 API Key，由维护者创建并录入。

## 按用途配置

| 用途 | 调用方 | 要求 |
| --- | --- | --- |
| 智能体 | 通用视觉智能体选下一步动作 | 看重定位准确率与时延，思考关闭或最低 |
| 推理 | planner 的审判推理与决策候选 | 开启思考 |
| 摘要 | planner 的批量更新 | 看重费用，思考关闭 |
| 关键帧 | planner 在关键帧上的多模态调用 | 见[游戏笔记](narrative-planner.md#游戏笔记) |
| 标定 | 离线工具生成快路径签名候选 | 见[快路径](game-adapter.md#快路径) |

每个用途配置：端点、型号、凭据名、思考开关或档位、输出方式（`json_object` 或 `json_schema`）、超时、最大输出长度、并发与速率上限、降级模型。视觉用途另配：

- **图像规格**：最长边与裁剪方式。
- **坐标约定**：模型返回发出图像上的像素坐标还是归一化坐标；客户端按坐标约定与当次的裁剪缩放换算回客户区物理像素。

缺省全部为方舟上的 `glm-5-3-flash`，用于测试；它的思考不能关闭，按 Bellis R-17 用 `reasoning_effort: low`。各用途的型号由 GS-07 对照后再定。换型号只改配置；以后由配置页面修改，配置页面的形式另行审核。

## 允许清单

发送游戏画面与文本受[合规确认 C-2](../compliance.md#合规确认) 约束，由客户端强制执行：

- 只能选游戏适配包合规声明中允许的厂商与型号，按厂商与请求 `model` 字段的完整值核对，与用途无关；清单外一律拒绝，配置与配置页面都不能越过。方舟上豆包系列写型号 ID；第三方模型（如 GLM）写已确认启用安全沙箱的那个接入点 ID，安全沙箱在方舟上按接入点启用，C-2 的确认也是对接入点做的。本仓库文档里的 `glm-5-3-flash` 是简写，指 Bellis R-17 所用的 `glm-5-3-flash-260828`。
- 适配包合规声明的 `models` 每项写 `vendor` 与 `model`，方舟的厂商标识为 `volcengine-ark`。每一项都须在 C-2 的范围内，校验适配包时核对：方舟上以 `doubao-` 开头的型号 ID，以及接入点 `glm-5-3-flash-260828`。这个范围在代码里只有一份（`game_runtime.adapter` 的 `c2_allows`），随 C-2 修改。
- 外发按主机授权（`net.egress:<主机>`）。
- 只发游戏窗口的画面，按图像规格裁剪缩小后再发，不带任何观众信息。
- 不作为示例图或少样本示例发送已存的游戏截图（C-1）；已存样本用于评测见 C-3。
- 向不在允许清单内的模型只能发非游戏的测试图像（GS-07）。

## 遥测

每次调用按用途记录：型号、token（含思考）、首字与完整时延、失败类别。供 GS-07 与[离线回放基准](offline-tools.md#离线回放基准)使用。

## 验收

| 阶段 | 内容 |
| --- | --- |
| G2 | 清单外的型号被拒绝且配置无法越过；坐标换算在不同裁剪缩放下正确；超时与降级生效；各用途的时延、费用与定位结果按 GS-07 实测记录 |

## 技术路线

已批准：GR-11、GR-18；合规 C-1、C-2。探针：GS-07。

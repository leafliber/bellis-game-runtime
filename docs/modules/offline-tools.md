# 离线工具

不进直播进程的本机工具：合成游戏夹具、录制、标定、经验审核与离线回放基准，以及并行的 VLA 研究工具。代码放在 `tools/`。产出的制品经批准才上线；从游戏派生的数据只存本地数据目录。G0 实现合成游戏，G1 实现录制与回放基准的样本格式，G2 起实现标定、回放基准与经验审核。

## 职责

- 提供不受任何游戏条款约束的合成游戏，供 CI、真机闭环与通用度基准使用。
- 在本机录制帧与标注，供评测与回放。
- 帮助操作员标定快路径签名、审核经验快路径候选。
- 以回放量化每次改动的影响。

## 不负责

- **训练《魔女审判》的任何模型。** 只评测，不训练（[合规](../compliance.md)）。
- **直播路径。** 工具的结果写入不入库的报告，不直接改变运行中的配置。

## 合成游戏

（GR-30）仓库内的一个小游戏，作为测试夹具，不受任何游戏条款约束，代码在 `tools/synthetic-game/`。

- **核心**：无窗口的状态机加 Pillow 渲染到像素缓冲，字体用 OFL 许可的 CJK 字体；画面含对话逐字显示、选项、计时选择、菜单、商店、弹窗与坏结局，文字速度、计时时长与分辨率可配置。
- **真机**：tkinter 外壳把缓冲显示成真实窗口，经 WGC 采集与 SendInput 驱动，跑完整闭环。
- **CI**：缓冲直接喂给假采集源，假输入后端的动作回送状态机，跑除采集与注入外的全链路；三平台都运行。
- **适配包**：G1 起配一份完整的适配包（[格式](game-adapter.md#格式)），是声明格式的第一个样例；快路径可整体关闭，用作通用视觉智能体的回归基准。
- 它只能证明链路通，不能代替真机验收（Bellis D-11）。

## 录制

- 录制帧与标注（画面类型、目标、正确的点击目标）存于本地数据目录，不进版本库，按游戏分开。
- 录制按该游戏的条款处理；《魔女审判》按 C-4（PENDING，确认前不录制）：只存本机，留存上限由维护者在首次建立基准时确定，样本与 GS-04、GS-07 共用。
- 游戏适配包的合规声明禁止时，示范记录器拒绝运行。

## 标定

- 操作员在本机截图上手工标定画面签名（锚点模板、像素检查、固定文字），模板按 C-1 从本机截图裁出，存于本地数据目录并按摘要引用。
- 可用“标定”用途的模型（[模型接入](models.md#按用途配置)）生成签名候选，受 C-2 允许清单约束；候选经操作员确认后才启用。

## 经验审核

操作员查看[经验快路径](game-adapter.md#经验快路径)的候选：裁出的锚点、动作、成功次数与失败记录；批准后才启用，暂停的快路径在这里复核。

## 离线回放基准

（GR-27）

- 每款游戏以录制帧与标注做 M0 回放，输入走假后端。
- 统计：命中、错点、拒绝、按坐标执行的结果、完成每个目标的步数、调用次数与费用（来自[模型遥测](models.md#遥测)）。
- **通用度指标**：快路径关闭时通用视觉智能体的成功率（合成游戏与各游戏的录制上）、适配包中必需项之外的内容量（签名、快路径与钩子的条数）、新游戏从接入到可玩的工时；每个阶段记一次，目标是逐游戏下降。
- 接入新游戏、换模型、启用快路径候选时以此为准；结果写入不入库的报告。
- 回放中把已存样本发给云端模型须先确认 C-3，确认前只用本地模型回放。
- CI 只用合成的测试图。

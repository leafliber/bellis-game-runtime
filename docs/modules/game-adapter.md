# 游戏适配包

针对一款游戏的适配，属于主进程关键平面，提供 `game-adapter@1`（GD-04）。通用视觉智能体是底座，适配包只须提供必需项就能以逐步模式运行；快路径按需添加，用来降低时延与费用、提高可靠性。适配成本降低了，但零样本通关仍不是目标（Bellis D-02）。各游戏的具体适配见 [docs/games/](../games/)。G1 实现《魔女审判》适配包的必需部分，G2 加快路径。

## 职责

- 认定游戏窗口，声明动作白名单、静态禁区与风险等级。
- 声明合规约束与允许的模型，由运行时执行。
- 提供快路径：画面签名与对应的确定性处理。
- 提供 planner 的笔记栏目、模式仲裁规则与操作员前置条件。

## 不负责

- **执行与把关。** 白名单与静态禁区由[实时核](realtime-core.md#白名单与静态禁区)执行，风险规则由[逐步控制](step-control.md#动作风险)执行。
- **存放从游戏派生的东西。** 模板、截图与录制只存本地数据目录，见下文。

## 内容

| 类别 | 内容 | 使用方 |

| 必需 | 动作白名单：扫描码、鼠标键、点击区域、最高动作速率、最长按住时间、按住时长 | [实时核](realtime-core.md#白名单与静态禁区) |

## 位置与版本库边界

（GR-04）适配包放在本仓库 `games/<id>/`。

- **进版本库**：代码与配置，即上表的规则、白名单、ROI、参数、声明与笔记栏目定义。
- **不进版本库**：从游戏派生的东西（截图裁出的锚点模板、评测用截图与录制、经验与快路径候选）与模型制品。由本机工具生成或放入版本库外的本地数据目录，以版本与摘要引用；本机能否使用游戏截图以[合规](../compliance.md#合规确认)为准。
- **制品**：布局与模板、模型权重、提示词以版本加摘要加批准记录管理；更换制品等同改配置，持有输入许可时不生效。
- 需要不同的授权或合规边界、出现外部贡献、或发布节奏明显不同时，再拆为独立仓库，按 `game-adapter@主版本` 接回。

## 合规声明

适配包声明该游戏的文本来源与训练用途等约束，以及允许接收游戏画面与文本的模型厂商与型号。运行时执行：

- [模型接入](models.md#允许清单)只向清单内的模型外发。
- 示范记录器与训练工具读到禁止声明即拒绝运行。

## 快路径

快路径为高频或有时限的画面提供确定性处理，命中时代替通用视觉智能体决定动作；有时限的画面与高频动作（如对白推进）须有快路径。签名的判别见[感知](perception.md#画面变化与签名)。

快路径有三个来源，都在操作员确认后才启用：

- **手写**：在适配包中编写规则，签名手工标定。
- **VLM 辅助标定**：离线工具用“标定”用途的模型生成签名候选（[离线工具](offline-tools.md#标定)）。
- **经验快路径**：见下文。

标定产物不进版本库；CI 只用合成的测试图。

## 经验快路径

（GR-22）只记录与匹配，不训练任何模型。

- **记录**：动作执行后效果核验通过即记一条经验，含画面指纹（降采样画面哈希，遮掉变化区域；画面上的固定 OCR 文字；观察到的画面类型）、归一化后的目标、动作（动作类型与目标的 OCR 文字或界面元素，不存原始坐标，下次在当前帧上重新定位）、预期效果与核验结果。只记普通等级的推进类与导航类动作；选择类、不可逆与禁止等级不记。
- **候选**：同类画面、同类目标连续成功若干次（缺省 3 次）且动作一致，即生成快路径候选（从本机帧裁出的锚点模板加固定文字、动作规则、预期效果）。离线回放基准可用后，候选先在基准上验证。
- **审核**：操作员在本机工具中查看裁出的锚点、动作、成功次数与失败记录，批准后才启用（[离线工具](offline-tools.md#经验审核)）。
- **运行**：命中后照样核验效果，失败一次即这一步退回通用视觉智能体，该快路径暂停待复核；游戏或适配包版本变化时相关快路径全部暂停；签名命中率下降时告警。
- **存储**：经验与候选存于本地数据目录，按游戏、适配包版本与分辨率分开，不进版本库。操作员可手动把不从游戏派生的规则部分并入适配包配置，锚点模板始终不进版本库。只保留生成签名所需的裁剪区域，完整帧在候选生成或审核后删除，留存有上限（C-1）。
- **外发**：经验不作为示例图发给云端模型，只可给智能体简短的文字提示。

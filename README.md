# Bellis Game Runtime

Bellis 的游戏运行时：负责游戏画面采集、感知（OCR、VLM 等）、VLA 控制策略、唯一的输入代理（Input Broker），以及控制模型的数据与训练。它是独立仓库和独立进程，通过公共契约向 Bellis 主播内核提供游戏能力，逐帧控制不经过 Bellis。

## 目标

在已适配的游戏中完全自主游玩，覆盖即时战斗、剧情理解和多样小游戏解谜，最终以 VLA 方式玩原神这类游戏。零样本通关未适配的游戏、直播中在线自动训练并上线，都不在目标内。

首个里程碑是配合 Bellis 公开试播《魔法少女的魔女审判》：AI 自主推进剧情；没有计时的选项由 AI 决定是否开观众投票，有计时的由 AI 自己选。

## 当前状态

尚无代码，也尚无现行设计。`docs/inherited/` 保存从 Bellis v0.8 冻结设计中移交过来的游戏控制材料，供重新设计时参考，不是本仓库的规范。每个模块的技术路线须经维护者审核后才写入正式设计。
